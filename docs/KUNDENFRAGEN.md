## C. Хостинг и эксплуатация (до выпуска; деплой вне задачи)
| # | Вопрос | Решение до ответа |
|---|---|---|
| C1 | Где будет хостинг? Требуется PHP ≥ 8.1 с `pdo_sqlite` и Apache (`.htaccess`) или эквивалентные правила | PHP + Apache предполагается |
| C2 | Как отправлять почту: `mail()` хостера или SMTP (сервер, порт, логин)? Какой адрес отправителя (`FROM_ADDRESS`) разрешён (SPF/DKIM)? | `log` локально; `mail` по умолчанию на хостинге |
| C3 | Можно ли вынести хранилище заявок за пределы webroot? | `storage/` с запретом доступа |
| C4 | Получатель заявок: `info@wahl-strassenbau.de` (как сейчас)? | да |
| C5 | Домен для canonical/OG: `https://www.wahl-strassenbau.de` (константа `SITE`)? | да |
| C6 | Стоит ли сайт за прокси/CDN (Cloudflare и т. п.)? Тогда в конфиге нужен `CLIENT_IP_HEADER`, иначе антиспам-лимит будет общим для всех посетителей | не задан (прямой хостинг) |
| C7 | Какие адреса сайта разрешены для отправки форм (`ALLOWED_ORIGINS`), например с/без www? | `https://www.wahl-strassenbau.de`, `https://wahl-strassenbau.de` (в примере конфига) |

## E. Публикация на Cloudflare (пакет `cloudflare/`, добавлено 2026-10-02)
| # | Вопрос | Решение до ответа |
|---|---|---|
| E1 | В Datenschutz сказано: «Die erhobenen Daten werden mit unserem Website-Hosting-Anbieter geteilt und innerhalb der EU verarbeitet.» Cloudflare — компания из США, запросы обрабатываются в глобальной сети. Нужны новая редакция текста о хостинге и договор об обработке данных (DPA/AVV) с Cloudflare. **Блокер публикации на домене** | текст не менялся; база заявок D1 создаётся с `--location=weur` (Западная Европа) |
| E2 | Чей аккаунт Cloudflare: заказчика или исполнителя? Для своего домена его DNS переносят в Cloudflare. Где сейчас зарегистрирован `wahl-strassenbau.de` и кто имеет доступ? Почтовые записи (MX, SPF) при переносе нужно сохранить, иначе перестанет работать почта `info@` | до решения: только адрес `*.workers.dev` |
| E3 | На Cloudflare нет `mail()`: письма из форм уходят только через SMTP почтового ящика (сервер, порт 587/465, логин, пароль). Какой ящик использовать (связано с C2)? | `MAIL_TRANSPORT=log`: заявки сохраняются в D1, письма **не** отправляются |
| E4 | C6 закрыт для Cloudflare: IP для антиспама берётся из `CF-Connecting-IP`, `CLIENT_IP_HEADER` не нужен | — |
