## Проблема
Wahl Straßenbau GmbH & Co. KG (Papendorf/Rostock) получила новый согласованный дизайн сайта в Figma
(«Wahl Straßenbau — Website 2026», fileKey `RftFK0Bf5MXWspQfaAshIj`). Текущий репозиторий содержит рабочий
статический сайт в другом стиле (Lamborghini, ветка `master` @ `1ebca29`). Заказчику нужен сайт, который выглядит и
ведёт себя как макет, с работающими формами, готовый к передаче без доработок. Прямого контакта с заказчиком нет:
неясности исполнитель решает сам, по правилам из spec, и документирует.

## Желаемый результат (наблюдаемый)
1. Все 14 страниц и состояние «Kontakt – Fehler» реализованы по Figma на 1440 / 1024 / 390 px (брейкпоинты ≤767 / 768–1279 / ≥1280).
2. URL совпадают с текущими (Jimdo-структура), SEO-разметка сохранена.
3. Формы Kontakt, Kurzanfrage и Widerruf работают с JS и без JS: валидация на клиенте и сервере, антиспам,
   письмо владельцу (адаптер `log` / `mail` / `smtp`), копия заявки в SQLite с автоудалением через 90 дней,
   Eingangsbestätigung для Widerruf.
4. Сайт запускается локально одной командой; пользователь получает рабочую ссылку `http://localhost:5178`.
5. Отчёт с результатами проверок, отклонениями от макета и списком вопросов заказчику.

## Пользователи и затронутые системы
- Посетители сайта (частные и публичные заказчики, в т. ч. аварийный сценарий «Havarie 24/7»), desktop и mobile.
- Владелец компании: получает заявки по e-mail; при необходимости выгружает копии через CLI.
- Системы: статическая сборка `build.py`, PHP-обработчик форм, SQLite-файл, почтовый транспорт хостинга (неизвестен).

## Границы
**Входит:** визуальный слой и разметка всех страниц, компоненты и состояния Figma, маршруты прототипа, формы (клиент + сервер),
хранение заявок, почтовый адаптер, локальный сервер, автоматические проверки, документация проекта.

**Не входит:** деплой, домен, DNS, выбор хостинга, реальная отправка писем, CMS / админка / логин, смысловая правка юридических
текстов, новые фото и факты, аналитика и трекеры, изменения в Figma, `git push` / merge в `master`.

## Ограничения
- Существующий стек сохраняется: статический HTML/CSS/JS без фреймворков, `python3 build.py`, PHP 8 для форм (решение владельца, ADR-0001).
- Новые runtime-зависимости запрещены (composer недоступен); локальные dev-инструменты разрешены.
- Факты только из `CONTENT.md`, handoff-материалов и текущих страниц; юридические тексты дословно.
- DSGVO: минимум персональных данных, срок хранения 90 дней (настраивается), без сторонних скриптов и шрифтов с CDN.
- Работа только на ветке `figma-2026`; `master` остаётся точкой отката.
- Бюджет: одна сессия Claude Code Opus 5.5 high; xhigh только по правилу эскалации в plan.md. Платные сервисы запрещены.

## Критерий «готово» (сводно; проверяемые критерии — AC-01…AC-12 в spec.md)
Владелец принимает сайт по локальной ссылке, отчёту `report.md` и списку `docs/KUNDENFRAGEN.md`; все AC имеют статус PASS
или принятое владельцем NOT RUN с причиной.
